- 사용자 지정 RAG 워크플로를 HTML과 JavaScript로 구현한다.
- 설계는 단순하게 유지하고, 20분 안에 완성할 수 있는 범위로 만든다.
- 캐싱, 클래스, 인터페이스는 구현하지 않는다.
- 다음 흐름만 구현한다: 사용자 입력 → Retrieve API → 컨텍스트 → 프롬프트 증강 → LLM → 답변.
- Retrieve API는 사용자 쿼리를 받아 (1) 쿼리 임베딩 생성, (2) 지식 기반에서 유사 문서 검색, (3) 검색된 문서 반환만 수행하는 함수 하나로 만든다.
- 유사도는 코사인 유사도로 계산하고 상위 3개 문서만 컨텍스트로 사용한다.
- 지식 기반 문서는 코드에 하드코딩하지 않는다. UI에서 사용자가 입력하거나 붙여넣은 텍스트를 그대로 지식 기반으로 사용한다.
- 임베딩과 LLM 호출은 브라우저에서 직접 API를 호출하고, API 키는 UI 입력 필드로 받는다.
- 프롬프트 증강은 "검색된 컨텍스트 + 사용자 입력"을 하나의 프롬프트 문자열로 합치는 방식으로만 한다.
- UI는 단일 HTML 파일에 지식 기반 입력란, 질문 입력란, 답변 영역, 사용된 컨텍스트 표시 영역만 둔다.
- 단위 테스트는 만들지 않는다. `node --check`가 통과하면 JavaScript는 유효한 것으로 본다.
- 앱은 PowerShell 스크립트로 로컬 HTTP 서버를 띄워 localhost:8080에서 실행한다.
- 경로 문제로 앱 실행이 어려우면 배치 스크립트를 만들어 실행한다.
