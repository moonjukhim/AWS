### 기존 AWS 계정의 AWS Control Tower 등록을 자동화(p50)

AWSAdministratorAccess는 Control Tower가 랜딩 존을 만들 때 IAM Identity Center에 생성하는 **권한 세트(Permission Set)**입니다. 여기에는 AWS 관리형 정책 **AdministratorAccess**가 붙어 있습니다. 즉 관리 계정의 모든 리소스에 대해 모든 작업을 허용하는 관리자 권한입니다.

1. 실제 정책 내용

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "*",
      "Resource": "*"
    }
  ]
}
```
- SCP는 관리 계정에 적용되지 않습니다. 그래서 관리 계정에서 이 권한은 사실상 제한이 없는 전체 권한입니다.

2. "임시 자격 증명"의 정체

    - 1. 권한 세트를 계정에 할당하면 해당 계정에 AWSReservedSSO_AWSAdministratorAccess_<랜덤값> 형태의 IAM 역할이 자동으로 생깁니다.
    - 2. Identity Center 포털에서 관리 계정의 AWSAdministratorAccess를 선택하고 **"Command line or programmatic access"**를 누르면, 이 역할을 수임한 STS 임시 자격 증명이 발급됩니다.
    ```text
    export AWS_ACCESS_KEY_ID=ASIA...
    export AWS_SECRET_ACCESS_KEY=...
    export AWS_SESSION_TOKEN=...
    ```
    - 3. 세션 기간은 권한 세트 설정을 따릅니다. 기본값은 1시간이고 최대 12시간까지 늘릴 수 있습니다. 장기 액세스 키가 아니라서 만료되면 자동으로 무효가 됩니다.
    - Control Tower는 기본적으로 이 권한 세트를 AWSControlTowerAdmins 그룹에 할당합니다.

3. 등록 스크립트에 이 권한이 필요한 이유

enroll_script.py는 관리 계정에서 다음 작업을 수행합니다.

| 단계 | 호출하는 서비스 | 필요한 권한 |
|---|---|---|
| 대상 계정과 OU 검증 | AWS Organizations | `organizations:Describe*`, `organizations:List*` |
| 대상 계정에 역할 생성 | CloudFormation StackSets (자동 배포) | `cloudformation:CreateStackSet`, `cloudformation:CreateStackInstances` 등 |
| 계정 등록 | Service Catalog (Account Factory 제품 시작) | `servicecatalog:ProvisionProduct` 등 |
| SSO 사용자 생성 | IAM Identity Center | `sso:*`, `identitystore:*` |

여러 서비스를 넘나들며 조직 전체에 영향을 주는 작업이라 관리자 권한을 쓰도록 안내하는 것입니다.

4. 헷갈리기 쉬운 두 역할 구분

| 구분 | AWSReservedSSO_AWSAdministratorAccess_xxx | AWSControlTowerExecution |
|---|---|---|
| 위치 | **관리 계정** | **대상(등록할) 계정** |
| 생성 주체 | Identity Center 권한 세트 | 스크립트가 StackSets로 생성 |
| 사용자 | 스크립트를 실행하는 사람 | Control Tower 서비스 |
| 신뢰 대상 | Identity Center(SAML) | 관리 계정 (`arn:aws:iam::<관리계정ID>:root`) |
| 연결 정책 | AdministratorAccess | AdministratorAccess |

즉 AWSAdministratorAccess는 스크립트를 실행하는 사람의 권한입니다. AWSControlTowerExecution은 등록 후 Control Tower가 대상 계정을 관리할 때 쓰는 역할입니다.

5. 아키텍처 관점 주의점

- 범위가 매우 넓은 권한이므로 등록 작업에만 짧게 쓰는 것을 권장합니다. 모듈 2의 모범 사례인 "관리 계정 관리자 권한의 할당 제한"과 같은 맥락입니다.
- 자격 증명을 EC2에 붙여넣을 때는 셸 기록이나 파일에 남지 않도록 주의합니다. 작업이 끝나면 세션을 종료하는 것이 안전합니다.
