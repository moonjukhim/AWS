###  Control Tower로 스포크 계정을 만들 때 전달 규칙 공유와 연결 자동화하기 P41

| 단계   | 할 일                                    | 언제     | 자동화 방법                              |
|-------|------------------------------------------|---------|----------------------------------------|
| ① 공유 | 네트워크 계정의 전달 규칙을 RAM으로 OU에 공유 | 한 번만  | OU를 대상으로 공유하면 그 OU에 새로 들어오는 계정은 자동으로 공유를 받습니다. Organizations 연동 시 초대와 수락이 필요 없습니다. |
| ② 연결 | 공유받은 규칙을 새 계정의 VPC에 연결         | 계정, VPC마다 | 이 부분을 자동화해야 합니다. StackSets 자동 배포를 권장합니다. |

0. 사전 준비(관리 계정에서)

```bash
aws ram enable-sharing-with-aws-organization                          # RAM 조직 공유 활성화
aws cloudformation activate-organizations-access                      # StackSets 신뢰할 수 있는 액세스 활성화
# 선택: 네트워크 계정을 StackSets 위임 관리자로 지정
aws organizations register-delegated-administrator \
  --account-id <네트워크계정ID> --service-principal member.org.stacksets.cloudformation.amazonaws.com
```


1. 네트워크 계정: 전달 규칙을 만들고 OU에 공유 (한 번)

```yaml
# network-dns-share.yaml
AWSTemplateFormatVersion: '2010-09-09'
Description: Forwarding rule to on-premises DNS, shared with an OU through AWS RAM
Parameters:
  OutboundEndpointId: {Type: String}          # rslvr-out-xxxx
  DomainName:         {Type: String, Default: example.com}
  OnPremDns1:         {Type: String, Default: 192.168.10.53}
  OnPremDns2:         {Type: String, Default: 192.168.20.53}
  ManagementAccountId:{Type: String}
  OrgId:              {Type: String}          # o-xxxx
  SpokeOuId:          {Type: String}          # ou-xxxx-yyyy
Resources:
  ForwardRule:
    Type: AWS::Route53Resolver::ResolverRule
    Properties:
      Name: onprem-forward
      RuleType: FORWARD
      DomainName: !Ref DomainName
      ResolverEndpointId: !Ref OutboundEndpointId
      TargetIps:
        - {Ip: !Ref OnPremDns1, Port: '53'}
        - {Ip: !Ref OnPremDns2, Port: '53'}
  RuleShare:
    Type: AWS::RAM::ResourceShare
    Properties:
      Name: onprem-dns-rules
      AllowExternalPrincipals: false
      ResourceArns: [!GetAtt ForwardRule.Arn]
      Principals:
        - !Sub arn:${AWS::Partition}:organizations::${ManagementAccountId}:ou/${OrgId}/${SpokeOuId}
Outputs:
  ResolverRuleId:
    Value: !GetAtt ForwardRule.ResolverRuleId   # ②의 StackSet 파라미터로 전달
```

2. 스포크 계정 기준선: StackSets 자동 배포 (권장)

OU에 계정이 들어오는 순간 CloudFormation이 그 계정에 스택을 자동으로 배포합니다. Account Factory가 계정을 OU에 만들기 때문에 별도 트리거가 필요 없습니다.

```yaml
# spoke-dns-baseline.yaml
AWSTemplateFormatVersion: '2010-09-09'
Description: Spoke VPC baseline - VPC from IPAM and association with the shared on-premises forwarding rule
Parameters:
  IpamPoolId:     {Type: String}              # RAM으로 같은 OU에 공유된 IPAM 풀
  NetmaskLength:  {Type: Number, Default: 22}
  ResolverRuleId: {Type: String}              # ①의 출력
Resources:
  SpokeVpc:
    Type: AWS::EC2::VPC
    Properties:
      Ipv4IpamPoolId: !Ref IpamPoolId         # 계정마다 겹치지 않는 CIDR 자동 할당
      Ipv4NetmaskLength: !Ref NetmaskLength
      EnableDnsSupport: true                  # VPC +2 Resolver 사용에 필수
      EnableDnsHostnames: true
      Tags: [{Key: Name, Value: spoke-vpc}]
  OnPremRuleAssociation:
    Type: AWS::Route53Resolver::ResolverRuleAssociation
    Properties:
      Name: onprem-forward
      ResolverRuleId: !Ref ResolverRuleId
      VPCId: !Ref SpokeVpc
  # 실제 온프레미스 통신까지 하려면 서브넷과 AWS::EC2::TransitGatewayAttachment
  # (RAM으로 공유된 TGW)를 이 템플릿에 함께 넣으세요.
```

- 배포(관리 계정 또는 위임 관리자 계정):

```bash
aws cloudformation create-stack-set --stack-set-name spoke-dns-baseline \
  --template-body file://spoke-dns-baseline.yaml \
  --permission-model SERVICE_MANAGED \
  --auto-deployment Enabled=true,RetainStacksOnAccountRemoval=false \
  --parameters ParameterKey=IpamPoolId,ParameterValue=ipam-pool-xxxx \
               ParameterKey=ResolverRuleId,ParameterValue=rslvr-rr-xxxx
#  (위임 관리자 계정에서 실행할 때는 --call-as DELEGATED_ADMIN 추가)

aws cloudformation create-stack-instances --stack-set-name spoke-dns-baseline \
  --deployment-targets OrganizationalUnitIds=ou-xxxx-yyyy --regions ap-northeast-2 \
  --operation-preferences FailureToleranceCount=1,MaxConcurrentCount=5
이후 Account Factory로 Workloads OU에 계정을 만들면 VPC 생성과 규칙 연결이 자동으로 완료됩니다.
```
