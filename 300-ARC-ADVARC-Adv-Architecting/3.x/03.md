###  자동화 구조

```text
[네트워크 계정 — 한 번 구축]  (CfCT / LZA / Terraform 파이프라인)
  ├─ TGW(VpnEcmpSupport) + 라우팅 테이블
  ├─ Site-to-Site VPN × 2 (고객 게이트웨이 2대, BGP, 필요하면 가속)  ← 장비 설정 샘플을 자동 생성해 전달
  ├─ DX 게이트웨이 + 전송 VIF + TGW 연결 (허용 접두사 = IPAM 상위 대역)   ← 물리 회선 준비 후
  ├─ Client VPN 엔드포인트 (ACM 인증서, SAML, 연결 핸들러 Lambda)
  └─ Resolver 엔드포인트, 전달 규칙, Route 53 Profile → RAM으로 OU에 공유

[계정 발급 — 반복]
  ⑤ AFC / ④ AFT : VPC, TGW 연결, Route 53 Profile(또는 규칙) 연결
  ⑥ Lambda       : TGW 라우팅 연결과 전파, Client VPN 경로와 권한 부여 규칙,
                   (필요 시) DX 허용 접두사 추가 → Reachability Analyzer로 검증

[운영 자동화 — 상시]
  CloudWatch 알람 : VPN TunnelState, DX ConnectionState와 BGP 상태
  EventBridge     : AWS Health(터널, DX 유지 보수), 퇴사자 → Client VPN 세션 종료
  정기 작업       : DX 장애 조치 테스트, 인증서 만료 점검, 연결 로그 리포트
```
