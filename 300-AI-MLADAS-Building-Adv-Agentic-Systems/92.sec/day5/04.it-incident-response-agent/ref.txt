아키텍처 설계 활동(p.12–13)용 참고 예제: 01-conversational-agents/SRE-agent

슬라이드 13의 활동은 오케스트레이터 에이전트가 전문가 에이전트 4개(각자 전용 도구 보유)를 지휘하는 구조입니다. SRE-agent가 이와 같은 구조입니다: supervisor 아래 Kubernetes, Logs, Metrics, Runbooks 에이전트 4개(graph_builder.py:148-178)가 있고, _filter_tools_for_agent가 에이전트마다 도구를 나눠 줍니다. 활동 질문 4개에도 모두 답을 찾을 수 있습니다.

1. 통신·오케스트레이션과 컨텍스트 최적화: supervisor 라우팅, 메모리 전략 3종, 메시지 트리밍 (모듈 02에서 정리한 내용)
2. 프로덕션 배포: AgentCore Runtime과 Gateway(MCP, 시맨틱 검색)
3. 보안: Cognito JWT, API 키 자격 증명 공급자
4. 관찰성·평가: OTel 계측

전자상거래 도메인을 SRE 도메인으로 바꿔서 구조를 비교해 보는 방식으로 쓸 수 있습니다.
