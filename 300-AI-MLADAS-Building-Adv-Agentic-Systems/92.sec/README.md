### Well-Architected Framework : Generative AI Lens

- 지속가능성(Sustainability)
  - SUS 1. 생성 형 AI 워크로드의 학습, 맞춤 설정 및 호스팅에 필요한 컴퓨팅 리소스를 최소화하는 방법은 무엇입니까?
  - SUS 2. 에너지 소비를 최소화하고 효율성을 극대화하기 위해 데이터 처리 및 저장을 최적화하는 방법은 무엇입니까?
  - SUS 3. 대규모 언어 모델을 다룰 때 모델 효율성과 리소스 최적화를 어떻게 유지합니까?
- 운영우수성(Operational Excellence)
  - OPS 1. 모델 출력 품질의 일관성을 어떻게 확보하고 검증할 수 있을까요?
  - OPS 2. 애플리케이션의 운영 상태를 어떻게 모니터링하고 관리하시나요?
  - OPS 3. 모델, 프롬프트 및 자산에 대한 추적성을 어떻게 유지하시나요?
  - OPS 4. 생성형 AI 워크로드의 수명주기 관리를 자동화하는 방법은 무엇인가요?
  - OPS 5. Gen AI 모델 맞춤 설정을 언제 실행해야 하는지 어떻게 판단하나요?
- 비용 최적화(Cost Optimization)
  - COST 1. 비용을 최적화하기 위해 적절한 모델을 어떻게 선택해야 할까요?
  - COST 2. 비용 효율적인 가격 모델(예: 프로비저닝 방식, 온디맨드 방식, 호스팅 방식, 배치 방식)을 어떻게 선택해야 할까요?
  - COST 3. 비용을 최적화하도록 프롬프트를 설계하는 방법은 무엇입니까?
  - COST 4. 벡터 스토리지를 비용 효율적으로 최적화하는 방법은 무엇인가요?
  - COST 5. 상담원 워크플로우를 비용 효율적으로 최적화하는 방법은 무엇인가요?
- 성능 효율성(Performance Efficiency)
  - PERF 1. 실제 운영 환경에서 생성형 AI 모델의 성능을 어떻게 측정하고 개선할 수 있을까요?
  - PERF 2. 생성형 AI 워크로드가 허용 가능한 성능 수준을 유지하는지 어떻게 확인할 수 있습니까?
  - PERF 3. 고성능 분산 컴퓨팅 작업에 필요한 컴퓨팅 리소스를 최적화하는 방법은 무엇입니까?
  - PERF 4. 데이터 검색 시스템의 성능을 어떻게 향상시킬 수 있을까요?
- 신뢰성(Reliability)
  - REL 1. 기초 모델의 처리량 할당량(또는 필요량)은 어떻게 결정하나요?
  - REL 2. 생성형 AI 아키텍처의 여러 구성 요소 간에 안정적인 통신을 유지하려면 어떻게 해야 할까요?
  - REL 3. 생성형 AI 워크로드의 반복 실행, 재시도 및 실패에 대한 복구 조치를 어떻게 구현합니까?
  - REL 4. 프롬프트, 모델 매개변수 및 기본 모델의 버전을 어떻게 관리합니까?
  - REL 5. 추론 워크로드를 여러 가용성 지역에 분산시키는 방법은 무엇입니까?
  - REL 6. 성공적인 완료율을 극대화하기 위해 고성능 분산 컴퓨팅 작업을 어떻게 설계해야 할까요?
- 보안(Security)
  - SEC 1. 생성형 AI 엔드포인트에 대한 접근 권한은 어떻게 관리하시나요?
  - SEC 2. 생성형 AI 애플리케이션이 유해하거나 편향되거나 사실과 다른 답변을 생성하는 것을 어떻게 방지할 수 있을까요?
  - SEC 3. 생성형 AI 워크로드와 관련된 이벤트를 어떻게 모니터링하고 감사합니까?
  - SEC 4. 시스템 및 사용자 프롬프트를 어떻게 보호합니까?
  - SEC 5. 모델의 과도한 에이전시 활동을 어떻게 방지할 수 있을까요?
  - SEC 6. 데이터 오염 위험을 어떻게 탐지하고 해결합니까?
