평가 범위와 정책 설계 참고

이 파일은 이번 실습에 필요한 자격 증명 기반 정책의 일부 문법을 평가합니다. 실제 SageMaker 학습, Bedrock 모델 호출, AWS IAM 전체 평가를 수행하지 않습니다.

지원 문법Effect, Action, Resource, Sid, Condition의 StringEquals·StringLike. *와 ? 와일드카드.
조건과 우선순위단일 문자열 요청 문맥. 키·연산자 사이는 AND, 한 키의 정책 값 배열은 OR. 매칭된 명시적 Deny가 Allow보다 우선하며, 허용이 없으면 암시적 거부.
평가하지 않는 범위신뢰·리소스 정책, SCP·RCP·권한 경계, 실제 STS와 PassRole 종속 검사, 서비스 작업·리소스 명세, 모델·리전의 실제 가용성.
미지원 문법NotAction·NotResource·Principal·정책 변수, 다른 조건 연산자·다중 값 요청 문맥은 추측하지 않고 오류로 표시합니다.
실제 적용 전AWS 공식 정책 검증과 실제 계정 테스트를 수행하세요. 24개 통과가 모든 요청의 최소 권한을 증명하지는 않습니다.
