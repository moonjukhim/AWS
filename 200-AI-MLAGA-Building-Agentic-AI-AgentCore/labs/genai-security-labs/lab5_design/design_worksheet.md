1. **반려동물 AI 돌봄 플랫폼**: 보호자 상담 챗봇 + 수의학 지식 RAG + 웨어러블 IoT 데이터 + 추천 엔진
2. **구급차 안의 기록 담당 AI**: 음성 → 구조화된 구급 기록 → 병원 응급실 전송
3. **진료한장**: 증상을 말로 설명 → 진료과 안내 → 진료 요약지 생성
4. **사내 HR 에이전트**: 직원 질의응답 + 휴가 신청·급여 조회 도구 호출
